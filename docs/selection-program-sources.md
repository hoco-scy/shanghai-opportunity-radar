# 选调／优培独立来源

本文件登记上海站每轮必须检查的选调／优培官方来源。上海市公务员局把市考和选调专题集中在同一官方系统中，因此这里是一个独立的**专题采集路径**，不是虚构的第二个政府域名。

| 来源 | 官方入口 | 采集方式 | 本轮完成标准 |
| --- | --- | --- | --- |
| 上海市公务员局选调生专题 | `https://www.shacs.gov.cn/` | 脚本读取官方专题目录、专题公告 JSON、详情和同域附件，只保留选调优培分类 | 选调相关专题及其公告详情均有访问证据；报名期或明确预公告进入匿名审核记录 |

## 生命周期与发布边界

1. 报名截止日未过的公告：下载公开职位表后，才可进入私有资格逐项判断。
2. 官方明确的预公告：记录为“职位表/报名期待公布”，持续追踪，但不写成具体可报岗位。
3. 历史公告、录用公示、资格审核和考试流程通知：仅作为来源健康与结构回归样本，不当作在招信息。
4. 任何职位都必须由单独的私有资格流程确认；本公开仓库和审核日志不存放个人身份、户籍、政治面貌等字段。

`node scripts/run-public-exam-sync.mjs --write` 会自动处理该专题；它与国考、市考同走公告采集、期限判断、匿名审核记录和门禁验证链路。
